## Resolution





Unlike the first challenge, where a payload generated by msfvenom was sufficient, here Windows Defender is active, which means that a raw payload would be immediately detected. So I decided to use a C program written by a friend RedTeamer to create a stealth reverse shell, by using advanced techniques like dynamic API resolution, random delays, and anti-VM checks to minimize the chance of detection.

Dapres lIntelligence Artificielle, Ce code utilise plusieurs techniques pour contourner Windows Defender :





Dynamic API Resolution: Functions like WSAStartup, WSASocket, and WSAConnect are resolved dynamically with GetProcAddress to evade static detection. Random Delay: Delay is introduced via NtDelayExecution. Anti-VM: Process checks evade sandboxes. Port 443: Blends into HTTPS egress traffic. Stealth Execution: Launches hidden cmd.exe via CREATE_NO_WINDOW.
